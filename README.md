# FOF Feed Generator

Bygger Meta-produktfeeds for alle FOF-skoler direkte fra FOF's søgeindeks i Azure AI Search: ét samlet feed og ét feed pr. skole. Kører automatisk i GitHub Actions.

**Dokumentation:** se [docs/README.md](docs/README.md).

## Live feed-URL'er

Samlet feed (alle skoler):

```
https://cdn.jsdelivr.net/gh/PelleDahl/FOF-Meta-feed@main/fof-alle-skoler-feed.xml
```
